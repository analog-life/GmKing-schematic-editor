Schematic Editor Help

Place components and shapes

Open Library to browse symbols and shapes. Press I to search for a component. The right column shows its name, symbol, and editable properties. Set any parameters, choose Place, then click the canvas. You can also edit an existing object in the main Properties panel.

Connect and label nets

Press W and click a pin, wire, or grid point to start a wire. The preview shows the snap point and the route. Click to add bends, then double-click or press Enter at the endpoint to finish. Press L, enter a net name, and confirm. Click near a wire or junction when the snap marker appears to place the label. Press Esc to cancel.

Net Labels are case-sensitive. Wires on the same sheet with identical labels are electrically connected. Use OUT<7:0> for a bus. To use one bit, draw a separate wire and label it OUT<3>.

Arrange the drawing

Use Layers to show, hide, or lock layers. Use Properties → Layer to move a selected object to a different layer. Press Ctrl+R to mirror across X or Shift+R to mirror across Y.

Press R to rotate the selection 90° in place. With an empty selection, press R, click a component to rotate it, then click the destination. Repeat for other components or press Esc to exit.

Press M to move with attached wires, Shift+M to move while leaving unselected wires in place, or C to copy. If objects are selected, click the destination to place them and finish. With an empty selection, click an object or drag a box from blank canvas to pick a group, then click its destination. You can keep picking and placing until you press Esc. Copying a subcircuit symbol on its sheet creates another instance of the same child sheet.

Add a note

Choose Note or press Shift+N. Enter text, set the font size, and choose one of the nine anchors. Press Enter to confirm, then click a snapped point on the canvas. Shift+Enter adds a line while entering text.

Use \(…\) for inline TeX and \[…\] for display TeX. Select a placed note to edit its text and anchor in Properties. SVG and PNG exports include the typeset formulas.

Build a hierarchical schematic

Open Hierarchy in the right dock and create a sheet. Press P to set a Pin Name, Type and Direction, then place the pin on the sheet and connect it. Edit an existing pin in Properties.

Choose Library → Hierarchy in the parent sheet to place the sheet symbol. Connect wires to the square terminals. Press E and click a symbol to enter its sheet. Press Ctrl+E to return one level. The Hierarchy panel shows the current path, included cells, pin list, and callers.

Pin names are case-sensitive. Use a range in a Pin Name to expose a bus on the sheet symbol, and connect it to a bus of the same width. The arrows in the pin list set its netlist order.

Renaming a pin preserves its connection. Moving a pin to another side or deleting it leaves parent wires where they are. Reconnect any loose ends in the parent sheet. Export Project JSON to save all sheets in one editable file.

Save and reopen a schematic

Workspace tabs are saved in this browser. Use the tab strip to import or paste schematic JSON into a new tab. Export JSON to keep an editable backup or export SVG or PNG to share an image.

Work with an AI Agent

Run npm run agent:connector from the Schematic Editor source folder. In the editor, choose AI → Hand off to AI → Copy text and paste the prompt into your local Agent. Allow local network access if the browser asks. Pairing uses a two-minute, single-use code. A paired session lasts up to two hours.

The dialog's Current status line follows manual editing, pairing, connection, suspension, and offline states. When paired, the green bar shows AI connected. You can edit normally. AI transactions use the latest project revision and enter the same Undo history. Suspend pauses AI access. Disconnect and Reclaim editing both revoke the session. The connector only listens on this computer.

Editor options

Use Language to switch between English and Simplified Chinese. Color mode can follow your system or stay in Light or Dark mode. Both settings are saved in this browser and also apply to this manual.

The gear or O opens Options, which also contains the current schematic's symbol template. Choose Wire crossings → Plain for straight crossings or Hop to show a bridge where wires cross without joining. Dots mark actual connections in either mode.

Wire angle sets the drawing mode to Orthogonal, 45 Degree, or Free. The preference is saved in this browser.

Default text font sets the font for the current schematic's notes and net labels. Select an individual note or net label and choose Properties → Font to override it or return to Document default. These settings are included in schematic JSON and used for image export.

Options → Process sets the default device models for this schematic. Select a transistor, resistor, capacitor or inductor and use Properties → Device model to override its model. Choose Custom as the process to enter model names directly. A blank custom field uses the process default. The process and overrides are stored in the schematic JSON and used for SPICE and Spectre output.

Schematic Editor 使用说明

放置元件和图形

打开器件库浏览符号和图形，或按 I 搜索元件。右栏依次显示器件名称、符号和可编辑属性。设置参数后选择放置，再点击画布。在画布上选中对象后，也可以在属性面板中编辑。

连接导线并命名网络

按 W，点击引脚、导线或网格点开始绘制。预览会显示吸附点和预计路径。单击添加拐点，在终点双击或按 Enter 完成。按 L 打开网络标签窗口，输入并确认网络名。导线或连接点附近出现吸附标记时，点击放置标签。按 Esc 取消。

网络标签严格区分大小写。同一张原理图内，标签名称完全相同的导线会电气相连。将标签设为 OUT<7:0> 可定义总线。需要使用某一位时，另画一段导线并标成 OUT<3>。

整理图纸

在图层中管理图层的可见性和锁定状态，通过属性 → 图层调整所选对象所属的图层。按 Ctrl+R 沿 X 轴镜像，按 Shift+R 沿 Y 轴镜像。

按 R 将选中的对象就地旋转 90°。没有选中对象时，按 R 后先点击器件旋转，再点击目标位置放置。可以继续旋转其他器件，或按 Esc 退出。

按 M 移动对象并拉伸相连导线，按 Shift+M 仅移动对象，按 C 复制。已选中对象时，点击目标位置即可放置并退出。没有选中对象时，先点击对象，再点击目标位置，可以连续拾取和放置，直到按 Esc 结束。

添加注释

点击注释或按 Shift+N，输入文本并选择字号和九个定位点之一。按 Enter 确认，再点击画布上的吸附点放置。输入时可用 Shift+Enter 换行。

用 \(…\) 插入行内 TeX，用 \[…\] 单独显示公式。选中已放置的注释，在属性中修改文本和定位点。SVG 和 PNG 导出会保留公式排版。

创建层次原理图

在右栏打开层次并新建子图。按 P 设置端口名称、类型和所在边，再到画布放置并接线。已有端口可在属性中修改。

在父图通过器件库 → 层次放置子图符号，将导线接到方框端子。按 E 后点选符号进入子图，按 Ctrl+E 返回上一层。层次面板显示当前路径、包含的子图、端口列表和引用。

Pin Name 严格区分大小写，也可使用总线范围。父图中的端子接入同宽总线。用端口列表中端口旁的箭头调整网表顺序。

端口改名会保留连接。修改所在边或删除端口时，父图导线保留在原处，可在父图手动重接悬空线头。导出项目 JSON可保存全部子图。

保存与重新打开图纸

工作区标签页保存在当前浏览器中。通过标签栏导入或粘贴电路 JSON，可在新标签页打开图纸。导出 JSON 可保留可编辑的备份，导出 SVG 或 PNG 可分享图像。

与 AI Agent 协作

在 Schematic Editor 源码目录运行 npm run agent:connector。在编辑器选择 AI → 交给 AI 修改 → 复制文本，将提示词粘贴给本机 Agent。若浏览器询问，请允许本地网络访问。配对码两分钟内可以使用一次，配对成功后会话最长持续两小时。

弹窗中的当前状态会随人工编辑、等待配对、已连接、暂停和离线状态更新。配对后，顶部绿条显示AI 已连接，仍可正常手工编辑。AI 事务按最新项目修订号提交，与手工操作使用同一个撤销历史。暂停连接会暂停 AI 访问。取消连接和收回编辑权都会撤销会话。连接器只监听本机。

编辑器选项

通过 Language 在英文和简体中文之间切换。颜色模式可跟随系统，也可固定使用亮色或暗色。两项设置均保存在当前浏览器，并应用于本说明。

点击齿轮或按 O 打开选项，可设置当前电路的符号模板。在 Wire crossings 中选择直线交叉（Plain）或跨线桥（Hop）。两种模式都用圆点表示真实连接。

在导线角度中选择正交、45 度或自由布线。此偏好保存在当前浏览器。

通过 Default text font 选择当前图纸的注释和网络标签默认字体。在属性 → 字体中可覆盖单个对象的字体，或恢复为文档默认值。这些设置随电路 JSON 保存，并用于图像导出。

选项 → 工艺决定当前原理图的默认器件模型。选中晶体管、电阻、电容或电感后，可在属性 → 器件模型中单独指定。工艺选择自定义时可直接输入模型名称，留空则采用工艺默认值。工艺和单个器件的模型设置随原理图 JSON 保存，并用于生成 SPICE 和 Spectre 网表。
